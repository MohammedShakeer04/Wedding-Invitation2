# Muslim Wedding Invitation Website

A responsive HTML/CSS/JavaScript wedding invitation for:

- Md Shahbaz Asgar weds Noushin Parveen — 7 April 2027

## Files

## Run

## Publish
Upload the folder to a GitHub repository and enable GitHub Pages.
